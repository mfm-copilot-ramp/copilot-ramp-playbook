# Quick Wins

The highest-return prompts across the journey — organized by the moment you're in. Copy, paste, fill in the `[brackets]`, send. Every prompt has a **full walkthrough** when you want the step-by-step, the tips, and the variants.

<p class="qw-lede">New here? Grab the one that matches what's in front of you right now — you'll have a win before your coffee's cold.</p>

## In a meeting

<div class="grid cards rc-grid qw-grid" markdown>

-   <span class="qw-title">After any meeting — tracked follow-ups</span>

    ```
    Summarize the meeting "[meeting name]" from [today/this morning]. Give me:
    - Decisions made
    - Action items, each with an owner and a due date
    - Any open questions that were not resolved
    Format the action items as a table I can paste into an email.
    ```

    <span class="rc-meta" data-time="5" data-roles="end-user manager champion"><span class="rc-chip rc-chip-time">⏱ 5 min</span> <span class="rc-chip rc-chip-role">👤 End user</span> <span class="rc-chip rc-chip-star">★ Starter</span></span>

    [Full walkthrough →](walkthroughs/chat-meeting-followups.md){ .qw-more }

-   <span class="qw-title">Before a 1:1 — prep in 2 minutes</span>

    ```
    Help me prep for my 1:1 with [name]. Summarize what we've been working on together
    over the last two weeks across email and Teams, flag anything still open or waiting
    on either of us, and suggest 3 topics worth raising. Keep it to half a screen.
    ```

    <span class="rc-meta" data-time="5" data-roles="manager champion"><span class="rc-chip rc-chip-time">⏱ 5 min</span> <span class="rc-chip rc-chip-role">👤 Manager</span></span>

    [Full walkthrough →](walkthroughs/chat-prep-1on1.md){ .qw-more }

-   <span class="qw-title">Before any meeting — agenda from context</span>

    ```
    I'm running a [30-minute project sync] with [audience] about [topic].
    Based on [these notes / this background], draft an agenda with time slots
    and a one-line goal for each item. Include a parking lot bucket at the end.
    ```

## Drowning in email

<div class="grid cards rc-grid qw-grid" markdown>

-   <span class="qw-title">Long email thread — catch up instantly</span>

    ```
    Summarize this email thread: what's the core issue, what options have been discussed,
    where do things stand now, and what (if anything) is being asked of me?
    ```

    <span class="rc-meta" data-time="5" data-roles="end-user manager"><span class="rc-chip rc-chip-time">⏱ 5 min</span> <span class="rc-chip rc-chip-role">👤 End user</span> <span class="rc-chip rc-chip-star">★ Starter</span></span>

    [Full walkthrough →](walkthroughs/chat-email-chain-summary.md){ .qw-more }

-   <span class="qw-title">Tough email — rewrite for the audience</span>

    ```
    Rewrite this email to be about 40% shorter and more direct, with a polite,
    confident tone for a skeptical executive who skims. Lead with the ask,
    keep one clear next step, and cut anything defensive. Don't change the facts.
    ```

    <span class="rc-meta" data-time="3" data-roles="end-user"><span class="rc-chip rc-chip-time">⏱ 3 min</span> <span class="rc-chip rc-chip-role">👤 End user</span></span>

    [Full walkthrough →](walkthroughs/chat-rewrite-email.md){ .qw-more }

-   <span class="qw-title">Exec briefing — from background materials</span>

    ```
    Based on [this document / the attached materials], draft a 5-point exec briefing
    for a 10-minute conversation with [audience]. Lead with the business outcome.
    Keep each point to one sentence. Flag the one thing most likely to generate a question.
    ```

    <span class="rc-meta" data-time="10" data-roles="manager champion"><span class="rc-chip rc-chip-time">⏱ 10 min</span> <span class="rc-chip rc-chip-role">👤 Manager</span></span>

    [Full walkthrough →](walkthroughs/chat-exec-briefing.md){ .qw-more }

## Planning my week

<div class="grid cards rc-grid qw-grid" markdown>

-   <span class="qw-title">Weekly status — from your activity</span>

    ```
    Based on my last 5 working days of email, Teams messages, and meetings, draft a
    5-bullet status update for my manager — what shipped, what's in progress, and
    what's blocked. Keep each bullet to one line, plain and skimmable.
    ```

    <span class="rc-meta" data-time="5" data-roles="end-user manager"><span class="rc-chip rc-chip-time">⏱ 5 min</span> <span class="rc-chip rc-chip-role">👤 End user</span></span>

    [Full walkthrough →](walkthroughs/chat-weekly-status.md){ .qw-more }

-   <span class="qw-title">Start of week — plan from your calendar</span>

    ```
    Look at my calendar and inbox for this week. Tell me:
    1. My three most important commitments and what I need to be prepared for each
    2. Any open threads or pending decisions I should close before Friday
    3. One meeting or task I can safely deprioritize this week
    ```

    <span class="rc-meta" data-time="5" data-roles="end-user manager"><span class="rc-chip rc-chip-time">⏱ 5 min</span> <span class="rc-chip rc-chip-role">👤 End user</span> <span class="rc-chip rc-chip-star">★ Starter</span></span>

    [Full walkthrough →](walkthroughs/chat-plan-week.md){ .qw-more }

-   <span class="qw-title">New project — first-draft plan</span>

    ```
    Draft a first-cut project plan for [goal] by [deadline]. Break it into phases with
    milestones, suggest an owner role for each workstream, and list the top 5 risks with
    a mitigation for each. Put the milestones in a table. Flag any assumptions you made.
    ```

    <span class="rc-meta" data-time="10" data-roles="manager maker"><span class="rc-chip rc-chip-time">⏱ 10 min</span> <span class="rc-chip rc-chip-role">👤 Manager</span></span>

    [Full walkthrough →](walkthroughs/chat-project-plan.md){ .qw-more }

-   <span class="qw-title">Stuck on a problem — structured options</span>

    ```
    I'm trying to [problem statement].
    Generate 5 approaches. For each: one-sentence description, key benefit,
    biggest risk, and what it would take to execute.
    Push me toward the one you'd recommend and include one I probably haven't considered.
    ```

    <span class="rc-meta" data-time="10" data-roles="end-user maker"><span class="rc-chip rc-chip-time">⏱ 10 min</span> <span class="rc-chip rc-chip-role">👤 End user</span></span>

    [Full walkthrough →](walkthroughs/chat-brainstorm.md){ .qw-more }

</div>

## Buried in documents

<div class="grid cards rc-grid qw-grid" markdown>

-   <span class="qw-title">Long document — role-specific summary</span>

    ```
    Summarize this document for a [your role]. Give me the 3 things I most need to
    know, anything that affects [your key concern], and any risks or open questions
    I should raise. Skip the background — assume I know the basics.
    ```

    <span class="rc-meta" data-time="3" data-roles="end-user manager"><span class="rc-chip rc-chip-time">⏱ 3 min</span> <span class="rc-chip rc-chip-role">👤 End user</span> <span class="rc-chip rc-chip-star">★ Starter</span></span>

    [Full walkthrough →](walkthroughs/chat-document-catch-up.md){ .qw-more }

-   <span class="qw-title">Adapt a document for a different audience</span>

    ```
    Rewrite this [document / email / summary] for [target audience].
    They care most about [outcome]. Adjust tone to be [more direct / less technical].
    Remove or explain jargon. Make the key ask unmissable — put it first.
    Target length: [3 bullets / one page / 200 words].
    ```
