# Stage 3 · Cowork

> **Let it run the work. Hand Copilot a multi-step task and let it work through it — the first taste of delegation, not just assistance.**

**The shift:** from "Copilot helps me with a step" to "Copilot owns the task." This is the hinge of the whole ramp — once you're comfortable delegating end-to-end work, building an agent that does it repeatedly becomes the obvious next move.

---

## When you're ready for this stage

You trust Copilot for single prompts and find yourself wishing it could just *finish the whole thing* — pull the inputs, do the steps, hand you a result. That's exactly what Cowork is for.

!!! question "Going the wrong way?"
    Cowork earns its overhead on real multi-step work. If you've spun up a session for **one rewrite,
    summary, or lookup**, you've overshot — [drop back to Chat](../right-sizing.md#cowork-to-chat).

## What you need

- **A Microsoft 365 Copilot license**, and **Cowork turned on for you** by your admin — it's generally available but off by default and billed in Copilot Credits. [How access and cost work ↓](#access-and-cost)
- A real, multi-step task with clear inputs (files, emails, a meeting) and a clear deliverable.
- Willingness to delegate — and to review the output rather than do each step yourself.

## Access and cost { #access-and-cost }

Cowork is **generally available** (since June 16, 2026), **off by default**, and billed per task in **Copilot Credits** on top of the Microsoft 365 Copilot license. Type **`/cost`** in Cowork any time to see what a task used. Expand for the details.

??? info "How Cowork is paid for"
    Copilot Cowork previewed in Frontier from March 30 and became **generally available worldwide on June 16, 2026**
    for work and school accounts ([announcement](https://www.microsoft.com/en-us/copilot/blog/2026/06/16/copilot-cowork-is-now-generally-available/)) —
    no Frontier enrollment needed. A few extras, like the **App** skill for building lightweight apps, are still Frontier-only.

    Microsoft splits Copilot into **everyday AI**, covered by the Microsoft 365 Copilot user license (USL), and
    **advanced AI** on **usage-based billing**. Cowork is advanced AI: it needs the USL *and* it draws
    **Copilot Credits** for every task
    ([USL vs. usage-based billing](https://learn.microsoft.com/microsoft-365/copilot/user-subscription-license-usage-based-billing)).

    - **What drives a task's cost:** model use, context retrieval, tool calls, and runtime. Billable activity
      includes model responses, tool and skill calls, image generation, and browser tasks.
    - **What it costs:** pay-as-you-go is **$0.01 per Copilot Credit**; a pre-purchase plan (P3) trades a
      commitment for a discount.
    - **The license doesn't cover it.** Unlike Copilot Chat or the built-in agents, a Microsoft 365 Copilot
      license does *not* zero-rate Cowork usage.

??? info "How an admin turns it on (spending policy)"
    1. **Set up usage-based billing** in the Microsoft 365 admin center (**Copilot → Cost Management**).
    2. **Create a spending policy that selects Cowork** and scopes the users or groups who should have it. The
       policy *is* the access control — anyone in scope can use Cowork, however small the limit.
    3. **Set limits and alerts** at the tenant, group, or user level. Limits reset monthly and don't carry over.
    4. **Decide on discovery.** If Cowork is discoverable but not enabled, users can request access in the app.

    If you managed Cowork during the Frontier preview: the old **Agents → All Agents → Cowork** control no longer
    decides who gets access — only a spending policy does
    ([Manage Copilot Cowork](https://learn.microsoft.com/copilot/cowork/cowork-admin-governance)).

??? info "Keep an eye on the meter"
    - Type **`/cost`** in Cowork to see the approximate credits the current task has used and how much of your
      monthly limit is left. It's free to run — but you can't check cost *before* running a task
      ([credit usage for Cowork tasks](https://learn.microsoft.com/microsoft-365/copilot/usage-based-billing-copilot-credits-cost)).
    - Hit your limit? Request more from inside Cowork; the request goes to your admin.
    - Planning a rollout? Use the [Credit Estimator → Copilot Cowork](../credit-estimator.md) or Microsoft's
      [Cowork cost estimator spreadsheet](https://aka.ms/CustomerCoworkEstimator).

??? info "What Cowork can do now"
    Since GA, Cowork has grown well past one-shot hand-offs ([Cowork overview](https://learn.microsoft.com/copilot/cowork/)):

    | Capability | What it means for this stage |
    | --- | --- |
    | **Scheduled prompts** and **event-driven tasks** | Recurring work (a weekly digest) and triggers (a matching email or Teams message) run without you — managed on the **Automations** tab. |
    | **Built-in skills** — Word, Excel, PowerPoint, PDF, Email, Scheduling, Meetings, Daily Briefing, Deep Research, and more | Real files and real actions, not descriptions of them. |
    | **Custom skills** (up to 50) | Capture a great run as a reusable skill — the heart of the [Skills Catalog](../skills.md). |
    | **Plugins** from the Microsoft 365 App Store | Partner skills and connectors your admin can deploy org-wide. |
    | **Model choice** and **Auto** | Pick a model per task, or let Auto choose — a lever on cost per task. |
    | **Approvals** | Cowork pauses for your go-ahead before sending, posting, or scheduling. |

    Use it on the web at [copilot.cloud.microsoft](https://copilot.cloud.microsoft), in the Microsoft Copilot
    desktop app for Windows and macOS, or on mobile.

!!! info "Security at this stage"
    Cowork chains many steps, but every one runs as *you* — including scheduled and event-driven tasks — and
    processes files in a temporary, isolated environment inside the **Microsoft 365 service boundary**.
    Multi-step doesn't mean wider access: Microsoft Purview and the unified audit log still apply.
    See the full picture in **[Security & Governance](../empowerment/security.md)**.
