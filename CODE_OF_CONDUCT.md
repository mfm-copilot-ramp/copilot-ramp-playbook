# Code of Conduct

The Copilot Ramp Playbook is a community project. We want it to be a friendly, welcoming, and
productive place for everyone — readers, contributors, and maintainers.

## Our standard

This project adopts the **Contributor Covenant, version 2.1** as its code of conduct.

The full text — including expectations, examples of acceptable and unacceptable behavior, scope, and
enforcement guidelines — is the canonical version published by the Contributor Covenant project:

- **Plain text:** <https://www.contributor-covenant.org/version/2/1/code_of_conduct/>
- **Markdown source:** <https://github.com/EthicalSource/contributor_covenant/blob/master/content/version/2/1/code_of_conduct.md>

By participating in this project — opening issues, submitting pull requests, joining discussions, or
otherwise contributing — you agree to abide by that document.

## Reporting concerns

If you experience or witness behavior that violates the Contributor Covenant in this project's spaces
(issues, pull requests, discussions, or other repository surfaces), please report it privately to the
maintainers:

- **Email:** **`<conduct-contact@example.com>`** *(maintainers: replace with a real, monitored address)*
- Or contact any maintainer listed in [`MAINTAINERS.md`](MAINTAINERS.md) directly.

All reports will be handled discreetly. Maintainers are responsible for reviewing reports and taking
appropriate action under the Contributor Covenant's enforcement guidelines (see "Enforcement
Responsibilities" and "Enforcement Guidelines" in the linked document).

## Scope

This applies to all project-managed spaces — the GitHub repository, its issues and pull requests,
discussions, and any other place where someone is representing the project or its community.
